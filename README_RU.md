## 📖 История: Roblox, аниме tower defense и уставшая рука

Я много играю в **Roblox** — особенно в аниме tower defense игры. Кто в теме, тот знает *этот цикл*:

> Поставил юнитов → ждёшь волну → собрал кристаллы → улучшил → повторил.
> И снова. И снова. **Сотни раз за вечер.**

Однажды, после третьего часа ручного кликанья по одним и тем же кнопкам, моя рука сказала *«нет»*. Я скачал **TinyTask** — и упёрся в потолок:

- 🕰️ интерфейс из эпохи Windows XP;
- 🔁 либо «повторять вечно», либо ничего — никакого «сыграй ровно 5 раз»;
- 🐌 нет скорости воспроизведения;
- 📦 закрытый код — хочешь фичу? *Хочешь сильнее.*

И я понял: **я хочу свой рекордер макросов** — современный, с точным числом повторов, поверх окна игры и полностью под моим контролем.

Так появился Macro Recorder. 🦀

---

## 🦀 Почему Rust?

- **Один .exe** — без установщиков и рантаймов (.NET/Python не нужны);
- **Потоки без страха** — хуки, воспроизведение с микросекундной точностью и UI живут в разных потоках и не мешают друг другу;
- **Надёжность** — программа, которая инжектит ввод, не должна падать посреди рейда;
- **Компактность** — с LTO + strip всё приложение весит несколько мегабайт;
- **Честно** — я хотел нормальный повод выучить Rust.

## 🆚 TinyTask vs Macro Recorder

| Фича | TinyTask | Macro Recorder |
|---|:---:|:---:|
| Лицензия | Бесплатная, закрытый код | **MIT, открытый код** |
| Интерфейс | Классика 2007-го | Современный GUI, **8 тем** (включая Mica / Acrylic на Win11) |
| Языки | Английский | **EN + RU**, автоопределение |
| Запись | Мышь + клавиатура | Мышь + клавиатура + **колесо + X1/X2** |
| Повтор | Только бесконечно | **Бесконечно или ровно N раз** |
| Скорость | Фиксированная | **0.1× – 3.0×** |
| Таймер записи | ❌ | ✅ |
| Счётчик проигрываний | ❌ | ✅ |
| Хоткеи | Фиксированные | **F8 / F9 — работают в любом окне** |
| Поверх всех окон | ✅ | ✅ с переключателем |
| Формат макроса | Проприетарный бинарник | **Читаемый JSON** |
| Размер | ~40 КБ | ~10 МБ *(зато с современным GUI и темами)* |
