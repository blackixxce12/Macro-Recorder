## 📖 История: Roblox, аниме-тавер-дефенсы и уставшая рука

Я много играю в **Roblox** — особенно в аниме tower defense игры. Если вы играли в подобные, то знаете этот *цикл*:

> Поставил юнитов → ждёшь волну → собрал гемы → апгрейд → повтор.
> И снова. И снова. **Сотни раз за сессию.**

Однажды вечером, после того как я в третий час подряд вручную нажимал те же кнопки «призвать / улучшить / забрать», моя рука сказала *«нет»*. Тогда я сделал то, что делают все — скачал **TinyTask**.

Он работал… минуты первые 10. Потом начались трещины:

- 🦖 **UI прямиком из Windows XP** — с 2007 года не постарел красиво;
- 🐛 **Закрытый Win32-блоб** с известными багами буфера ввода, которые молча теряют события при долгих записях (мой двухчасовой макрос для фарма рассинхронился через ~40 минут);
- 🎨 **Нулевая кастомизация** — та же серая трей-утилита, что у всех;
- 🐌 **Нет управления скоростью** — хочешь проигрывать 2× быстрее, чтобы протестировать макрос? *Обойдёшься*;
- 🚫 **Нет сохранения настроек по умолчанию** — при каждом запуске настраиваешь заново;
- 🔒 **Проприетарный формат** — хочешь отредактировать макрос вручную? *Захочешь ещё сильнее*.

И тогда я подумал: **хочу свой собственный рекордер макросов.** Такой, который:

- выглядит как приложение 2026 года, а не артефакт 2007-го;
- крутится **ровно N раз** *или* **заданное время** (и даже выключает ПК после);
- висит **поверх окна игры** с опциональным **прозрачным стеклянным UI**;
- и **полностью мой** — открытый для чтения, сборки и аудита всеми желающими.

Тот weekend-проект слегка вышел из-под контроля. 🦀

## 🦀 Почему Rust?

| Причина | Что это значит для тебя |
|---|---|
| **Один .exe** | Никаких инсталлеров, никакого .NET, никакого Python — один файл, двойной клик, готово |
| **Бесстрашная конкурентность** | Один поток ловит низкоуровневые хуки, другой проигрывает с микросекундным таймингом, третий рисует UI — и они никогда не конфликтуют |
| **Memory safety** | Инструмент, инжектирующий ввод в систему, не должен падать посреди рейда или переполнять буфер событий. Rust это гарантирует — никаких мистических багов из 17-летнего Win32-кода |
| **Компактный и мгновенный** | С LTO + strip всё приложение весит несколько мегабайт и запускается моментально |
| **Честная причина** | Мне нужен был реальный повод по-настоящему выучить Rust. Лучший способ учиться — делать то, чем реально пользуешься |

## 🆚 TinyTask против Macro Recorder

| Возможность | TinyTask | Macro Recorder |
|---|:---:|:---:|
| Лицензия | Freeware, **закрытый код** | **MIT, полностью open source** |
| Эпоха | 2007-вайбы (и поныне) | 2026 |
| UI | Классический серый трей-инструмент эпохи WinForms | Современный GPU-рендеренный GUI, **8 тем** (включая Windows 11 **Mica / Acrylic blur**), **прозрачный стеклянный режим** |
| Языки | Только английский | **6 языков** (EN, RU, UK, PT, ES, ZH) + автоопределение |
| Захват ввода | Мышь + клавиатура | Мышь + клавиатура + **колесо + X1/X2 кнопки** |
| Режим повтора | Бесконечный **или** N раз | Бесконечный, **N раз, или по таймеру** (часы + минуты) |
| Ограничение по времени | ❌ | ✅ стоп через Ч часов М минут |
| Действие по завершению | ❌ | **Остановить воспроизведение ИЛИ выключить ПК** |
| Скорость воспроизведения | Фиксированная | **0.1× – 3.0×** |
| Таймер записи | ❌ | ✅ текущий + финальная длительность |
| Счётчик воспроизведений | ❌ | ✅ живой счётчик в UI |
| Глобальные хоткеи | Фиксированные (аналог F8/F9) | **F8 / F9** — работают в любом окне, даже в игре |
| Поверх всех окон | ✅ | ✅ переключаемо |
| Прозрачность UI | ❌ | ✅ **полная прозрачность окна** |
| Сохранение настроек | ❌ — настройка каждый запуск | ✅ **сохранение по умолчанию** через `config.json` |
| Формат макросов | Проприетарный бинарный, склонный к повреждениям | **Человекочитаемый JSON**, редактируется вручную |
| High-DPI / мульти-мониторы | Так себе | Per-monitor DPI aware, фикс абсолютной мыши |
| Качество кода | ~17 лет закрытого Win32 C с известными багами переполнения буфера | ~1500 строк аудируемого Rust, ноль unsafe за пределами FFI |
| Размер | ~40 КБ | ~10 МБ *(включает современный GPU-UI, 8 тем и 6 переводов — папка `target/` на 960 МБ остаётся на моей машине, обещаю)* |
| Цена | Бесплатно | **Бесплатно навсегда** |

## ✨ Возможности

- 🔴 **Записывай** всё: движения мыши, клики, колесо, X-кнопки, клавиатуру
- ▶ **Проигрывай** с точным таймингом (`spin_sleep` + микросекундное планирование)
- 🔁 **Зацикливай** бесконечно, **ровно N раз** или **до лимита по времени**
- ⏱ **Лимит времени**: стоп через Ч часов / М минут, с опциональным **авто-выключением**
- ⚡ **Управление скоростью** 0.1× – 3.0×
- ⌨ **Глобальные хоткеи**: `F8` запись, `F9` воспроизведение — работают поверх любого окна
- 📌 Режим **Поверх всех окон** для игр
- 🪟 **Прозрачный UI** — сквозное стеклянное окно через DWM per-pixel alpha
- 🎨 **8 тем**: Dark, Material Design 3, Fluent (Mica), Catppuccin, Nord, Dracula, Glassmorphism (Acrylic), Neumorphism
- 🌍 **6 языков**: English, Русский, Українська, Português, Español, 中文 — автоопределение из системы, с возможностью переопределить
- 💾 **Сохранение настроек по умолчанию** — каждый следующий запуск помнит твою тему / язык / хоткеи
- 📦 Сохранение / загрузка макросов как **человекочитаемый JSON**

## 📥 Скачать

Скачай последний `.exe` со страницы **[Релизов](../../releases)**. Установка не требуется.

Доступны две сборки:

| Файл | Требования | Примечание |
|---|---|---|
| `MacroRecorder.exe` | Любой x86-64 CPU | Универсальная — запускается везде |
| `MacroRecorder.v3.exe` | CPU с AVX2 (Intel Haswell 2013+ / AMD Ryzen+) | Быстрее, компактнее |

> ⚠️ **Примечание про антивирусы:** инструменты для макросов инжектируют ввод, поэтому некоторые антивирусы могут помечать неподписанный exe как подозрительный (ложное срабатывание). Это нормально для такого ПО — именно поэтому исходники открыты: не стесняйся собрать самому.

## 🛠️ Сборка из исходников

```bash
# 1. Установи Rust: https://rustup.rs
# 2. Клонируй и собери
git clone https://github.com/blackixxce12/MacroRecorder.git
cd MacroRecorder

# Универсальная сборка
cargo build --release

# Оптимизированная сборка (AVX2, на ~5-20% быстрее на современных CPU)
# В CMD:
set RUSTFLAGS=-C target-cpu=x86-64-v3 && cargo build --release
# В PowerShell:
$env:RUSTFLAGS="-C target-cpu=x86-64-v3"; cargo build --release
