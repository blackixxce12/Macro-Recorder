# ⌨ Текстовый расширитель

### Руководство для человека, который никогда этим не пользовался

Вы набираете `адрес` и нажимаете пробел. Вместо этих шести букв появляется полный почтовый адрес в две строки. Вот и всё, что делает расширитель.

Программировать не надо. Есть список: слева короткое сокращение, справа длинный текст.

## 1. Зачем это нужно

Есть текст, который вы набираете снова и снова. Адрес. Номер карты лояльности. Подпись в письме. Шаблон ответа клиенту. Заготовка коммита. Реквизиты.

Каждый раз это двадцать-тридцать секунд и вероятность опечатки. Расширитель превращает их в четыре буквы.

Он работает **везде**: в браузере, в мессенджере, в почте, в редакторе кода, в игре. Программа следит за тем, что вы печатаете, и когда узнаёт сокращение — стирает его и печатает вместо него замену.

> **Важно понимать сразу:** это единственная функция во всей программе, которая вмешивается в обычный набор текста. Всё остальное работает только когда вы нажали «Воспроизвести». Поэтому расширитель **выключен по умолчанию**, и включать его надо осознанно.

## 2. Первая запись за две минуты

### Шаг 1. Найдите раздел

В главном окне разверните **⌨ Текстовый расширитель**.

### Шаг 2. Включите

Поставьте галочку **Разворачивать сокращения при наборе**.

### Шаг 3. Добавьте запись

Нажмите **+ Добавить**. Появится пустая строка.

- В поле **кратко** впишите: `тлф`
- В большое поле ниже впишите свой номер телефона

### Шаг 4. Проверьте

Откройте Блокнот. Наберите `тлф` и нажмите **пробел**.

Три буквы исчезнут, вместо них появится номер.

**Готово.** Всё остальное в этом руководстве — подробности.

> 💡 Ничего сохранять не нужно, запись уходит в файл сама.

## 3. Три способа срабатывания

Это главная настройка, и она задаётся **на каждую запись отдельно**. Столбец с выпадающим списком в строке записи.

### после разделителя — по умолчанию

Сокращение срабатывает, когда вы допечатали его **и нажали пробел** (или Enter, Tab, точку, запятую — любой знак из списка разделителей).

```
адрес + пробел  →  Москва, Тверская 1
```

**Почему так по умолчанию.** Это единственный способ, который не мешает обычному набору. Пока слово не кончилось, никто не вмешивается.

И у него есть приятное свойство: сокращения могут быть началом друг друга. Если у вас есть `под` и `подпись`, то `подпись` + пробел развернётся в длинный вариант — потому что решение принимается только когда слово закончилось.

### за префиксом

Сокращение срабатывает только если перед ним стоит метка: `;;`, `//`, `:` — что угодно, вы задаёте сами в поле рядом.

```
;;тлф  →  +7 900 000-00-00     (срабатывает сразу, без пробела)
тлф    →  ничего
```

**Когда брать.** Если сокращение — обычное слово, которое встречается в тексте. `мне`, `код`, `имя` в режиме по разделителю будут срабатывать посреди письма и сводить с ума. С префиксом — никогда.

### сразу

Срабатывает в тот момент, когда последние буквы совпали с сокращением. Пробел не нужен.

```
;подпись  →  С уважением, Иван     (мгновенно)
```

**Осторожно.** У этого режима есть свойство, которое надо знать: он **не умеет ждать**. Если у вас есть `;под` и `;подпись`, то короткое сработает на середине длинного — вы физически не успеете допечатать. Поэтому «сразу» годится только для сокращений, которые не являются началом других, и лучше с необычным символом впереди.

### по умолчанию

Значение по умолчанию наследуется из общей настройки **Срабатывание по умолчанию** над списком. Меняете там — меняется у всех записей, где стоит «по умолчанию».

## 4. Что можно вставлять кроме текста

В поле замены можно писать не только буквы. Всё в фигурных скобках — подстановка.

| Пишете | Получаете |
|---|---|
| `{date}` | `2026-08-18` |
| `{date:dd.MM.yyyy}` | `18.08.2026` |
| `{time}` | `01:23` |
| `{time:HH:mm:ss}` | `01:23:45` |
| `{datetime}` | `2026-08-18 01:23` |
| `{clipboard}` | То, что сейчас в буфере обмена |
| `{cursor}` | Курсор встанет сюда после вставки |
| `{key:Tab}` | Нажатие Tab |
| `{key:Enter}` | Нажатие Enter |
| `{random:да\|нет\|может быть}` | Одно слово из списка наугад |

### Про формат даты

Буквы в шаблоне: `yyyy` — год, `MM` — месяц, `dd` — день, `HH` — часы, `mm` — минуты, `ss` — секунды. Регистр важен: `MM` это месяц, а `mm` — минуты.

Всё остальное в шаблоне остаётся как есть, поэтому `{date:dd.MM.yyyy}` и `{date:dd/MM/yy}` работают одинаково хорошо.

### Про `{cursor}`

Ставьте туда, откуда хочется продолжить печатать.

```
Здравствуйте, {cursor}!

С уважением,
Иван
```

После срабатывания курсор окажется после «Здравствуйте, » — сразу пишете имя, не трогая мышь.

### Про `{key:...}`

Нужно для заполнения форм: Tab переходит к следующему полю.

```
Иван Петров{key:Tab}ivan@example.com{key:Tab}
```

Доступны: `Tab`, `Enter`, `Esc`, `Space`, `Backspace`, `Delete`, `Home`, `End`, `Up`, `Down`, `Left`, `Right`, `PageUp`, `PageDown`.

### Как написать фигурную скобку буквально

Поставьте перед ней обратный слэш:

```
буквально \{date} останется как есть
```

Незакрытая скобка и незнакомое слово внутри скобок остаются как написаны — это опечатка, а не команда, и молча съедать её было бы хуже.

### Многострочный текст

Просто нажимайте Enter в поле замены. Переносы сохранятся.

## 5. Печатать или вставлять

Второй выпадающий список в строке записи.

| | **печатать** | **вставить** |
|---|---|---|
| Как работает | По одному символу, как будто вы очень быстро набираете | Кладёт текст в буфер обмена и жмёт Ctrl+V |
| Работает везде | Да | Нет: в терминалах Ctrl+V часто не вставка |
| Длинный текст | Заметно медленнее | Мгновенно |
| Буфер обмена | Не трогает | Занимает на долю секунды и возвращает обратно |

**Что брать.** Оставьте «печатать». Переключайте на «вставить» только если замена длинная — от нескольких строк — и вы видите, как она печатается по буквам.

Буфер обмена возвращается на место автоматически. Но если у вас там было скопировано что-то не текстовое — картинка, файл, — вернуть его программа не сможет. Ещё один довод в пользу «печатать» по умолчанию.

## 6. Когда расширитель молчит

Это не менее важно, чем то, когда он срабатывает. Ложное срабатывание раздражает сильнее, чем несработавшее сокращение.

Он **не срабатывает**, если:

| Ситуация | Почему |
|---|---|
| Сокращение внутри слова: `подадрес` | Проверяется граница слова |
| Запись выключена галочкой | Очевидно |
| Общий тумблер выключен | Очевидно |
| Идёт **запись** макроса | Иначе замена попала бы внутрь макроса |
| Идёт **воспроизведение** макроса | Иначе он бы дрался с макросом |
| Вы кликнули мышью посреди слова | Курсор мог уехать куда угодно, что набрано — неизвестно |
| Вы нажали стрелку, Home, End, Esc | То же самое |
| Вы переключились в другое окно и вернулись | Набранное относилось к другому окну |
| Вы нажали Ctrl или Alt с клавишей | Это команда, а не набор |
| В заголовке окна есть слово из списка исключений | Вы сами так велели |
| Работает китайский или японский ввод (IME) | Программа не может знать, сколько символов стирать |
| Использована мёртвая клавиша (`´` + `e` → `é`) | То же самое: два нажатия, один символ |

Последние два случая — это отказ, а не поломка. Расширитель не гадает там, где не может посчитать точно.

### Список исключений

Поле **Молчать в окнах** над списком записей. Через запятую, сравнение по вхождению в заголовок, регистр не важен.

**Впишите туда менеджер паролей.** И терминал, если пользуетесь.

```
KeePass, Bitwarden, 1Password, PowerShell, cmd.exe
```

## 7. Файл expansions.json

Всё хранится в `expansions.json` рядом с настройками. Точный путь показан в главном окне в разделе **📁 Файлы**.

Кнопка **Открыть expansions.json** откроет его в редакторе, кнопка **Перечитать** подхватит правки обратно в программу.

Править руками нужно редко, но иногда удобнее — например, чтобы добавить тридцать записей разом или перенести список на другой компьютер.

```json
{
  "enabled": true,
  "default_trigger": "Delimiter",
  "delimiters": " \t\n.,;:!?)]}\"'",
  "excluded_windows": ["KeePass", "PowerShell"],
  "entries": [
    {
      "enabled": true,
      "abbr": "адрес",
      "text": "Москва, Тверская 1\nподъезд 2, кв. 15",
      "trigger": "Inherit",
      "insert": "Type"
    },
    {
      "enabled": true,
      "abbr": "тлф",
      "text": "+7 900 000-00-00",
      "trigger": { "Prefix": ";;" },
      "insert": "Type"
    }
  ]
}
```

Соответствие названий:

| В интерфейсе | В файле |
|---|---|
| по умолчанию | `"Inherit"` |
| после разделителя | `"Delimiter"` |
| за префиксом | `{ "Prefix": ";;" }` |
| сразу | `"Instant"` |
| печатать | `"Type"` |
| вставить | `"Paste"` |

> ⚠️ Перенос строки в JSON пишется как `\n`, а не настоящим Enter.
>
> ⚠️ Сломаете JSON — программа откажется его читать и напишет об этом в лог. Файл при этом не перезаписывается, так что правку можно найти и исправить.

## 8. Готовые примеры

### Подпись в письме

```
Сокращение:  ;подп        Режим: сразу
Замена:
С уважением,
Иван Петров
+7 900 000-00-00
```

### Дата в имени файла

```
Сокращение:  дд           Режим: после разделителя
Замена:      {date:yyyy-MM-dd}
```

### Заготовка ответа с курсором в нужном месте

```
Сокращение:  отв          Режим: после разделителя
Замена:
Здравствуйте!

{cursor}

Если появятся вопросы — пишите.
```

### Заполнение формы одним сокращением

```
Сокращение:  ;;форма      Режим: за префиксом (;;)
Замена:      Иван Петров{key:Tab}ivan@example.com{key:Tab}+79000000000
```

### Обернуть скопированное в кавычки

```
Сокращение:  цит          Режим: после разделителя
Замена:      «{clipboard}»
```

### Длинный шаблон договора

```
Сокращение:  дог          Режим: после разделителя
Способ:      вставить
Замена:      ...полторы страницы текста...
```

## 9. Частые грабли

| Симптом | Причина | Что делать |
|---|---|---|
| Ничего не происходит | Тумблер или запись выключены | Проверьте обе галочки |
| Ничего не происходит | Сокращение пустое | Пустые записи пропускаются |
| Ничего не происходит | Окно в списке исключений | Проверьте поле **Молчать в окнах** |
| Ничего не происходит, но раньше работало | Идёт запись или воспроизведение макроса | Нажмите `F9` |
| Срабатывает посреди слова | Режим «сразу» на коротком сокращении | Переключите на «после разделителя» или добавьте префикс |
| Длинное сокращение не срабатывает, срабатывает короткое | Режим «сразу» не умеет ждать | Смените на «после разделителя» |
| Замена в одну строку, хотя должна быть в две | Приложение не приняло перенос | Попробуйте в другом приложении; в некоторых полях перенос запрещён |
| После смены раскладки сработало не то | Сокращение оказалось «в начале слова» | Известное ограничение, см. ниже |
| Текст печатается медленно и видно каждую букву | Замена длинная, режим «печатать» | Переключите на «вставить» |
| Буфер обмена испортился | Там было не текстовое содержимое | Используйте «печатать» для этой записи |
| `{date}` вставился как есть | Опечатка в имени токена | Незнакомые токены остаются как написаны — сверьтесь с таблицей |

### Про смену раскладки

Если переключить раскладку **мышью** через языковую панель посреди слова, буфер набранного очистится — программа считает клик поводом забыть, что было. И следующее сокращение может показаться началом слова.

Переключение клавишами (Alt+Shift, Win+Space) обработано и такой проблемы не создаёт.

## 10. Чего он не умеет

Честный список, чтобы не искать несуществующее.

- **Нет форм с полями.** `{form:Имя}` не существует. Это отдельное окно с полями и валидацией — возможно, позже.
- **Нет `{selection}`.** Прочитать выделенный текст в чужом приложении нечем: единственный путь — послать Ctrl+C и забрать из буфера, а это ломает буфер и работает не везде. К тому же расширитель срабатывает на набор, а набор поверх выделения его и так заменяет.
- **Нет отмены по Backspace.** Развернулось не то — стирайте руками.
- **Нет учёта регистра.** `АДРЕС` и `адрес` — одно и то же сокращение, и замена всегда такая, как записана.
- **Нет вложенности.** Замена не может содержать другое сокращение.
- **Нет условий и переменных.** Для этого есть [скрипты](SCRIPTS_RU.md) — они про другое, но умеют думать.
- **Максимум 64 символа памяти.** Сокращение длиннее не сработает. На практике это не ограничение.

## 11. Про приватность

Скажу прямо, потому что это заслуживает прямого разговора.

Чтобы узнать сокращение, программа держит в памяти то, что вы **только что набрали**. Это короткий шаг от того, что держит клавиатурный шпион, и было бы нечестно об этом умолчать.

Что сделано, чтобы граница оставалась ясной:

1. Буфер ограничен **64 символами**.
2. Он **никогда не попадает в лог** — ни на одном уровне подробности, включая отладочный.
3. Он **никогда не пишется на диск**.
4. Он очищается при смене активного окна, клике мышью, стрелках и любом сочетании с Ctrl или Alt.
5. Он не существует вообще, пока расширитель выключен — а выключен он по умолчанию.

Что вы можете сделать сами:

- Внести менеджер паролей в **Молчать в окнах**. В таком окне буфер не наполняется вовсе.
- Выключать расширитель, когда он не нужен.
- Проверить всё вышесказанное: [исходный код открыт](https://github.com/blackixxce12/Macro-Recorder), модуль называется `expander`.

## 12. Шпаргалка

**Где:** главное окно → **⌨ Текстовый расширитель**

**Добавить:** **+ Добавить**, слева сокращение, снизу замена

---

**Режимы срабатывания**

```
после разделителя   адрес + пробел        безопасно, берите это
за префиксом        ;;адрес               для коротких и обычных слов
сразу               ;подпись              только для необычных сокращений
по умолчанию        берёт общую настройку
```

**Подстановки**

```
{date}  {date:dd.MM.yyyy}  {time}  {datetime}
{clipboard}   {cursor}   {key:Tab}   {random:а|б|в}
\{date}  — буквальные скобки
```

**Способ вставки**

```
печатать   везде работает, для длинного текста медленно
вставить   мгновенно, но не везде и занимает буфер обмена
```

---

**Три вещи, о которых забывают чаще всего**

1. Расширитель **выключен по умолчанию** — включите общий тумблер.
2. Во время записи и воспроизведения макроса он **молчит специально**.
3. Менеджер паролей стоит внести в **Молчать в окнах**.
